# The redesign's floors (designs/redesign/redesign.md §1): each module of src/ and the floor it moves to.
# A module may use its own floor and the floors below: base < catalog < engine < extensions < hosts.
# platform: implementations of base's traits (store, network, crypto, members); only hosts reach them.
# An extension module names its extension after a colon; extensions never use each other's modules.
# `tools/layers.py` checks src/ against this map and tools/layers-baseline.txt (the edges main had).
