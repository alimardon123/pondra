Each design note records one decision and the reasons for it. You don't need them to use Pondra: the
other pages say what it does. Read them when you want to know why. They are in the repository's
[`docs/`](https://github.com/alimardon123/pondra/tree/main/docs) folder, and each link below opens
the full text on GitHub. The status is as each note says it.

Some notes were written as proposals and then built on by later ones, and still say "Proposed".
