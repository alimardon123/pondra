`pondra.spark` has PySpark's names, and each one runs on a Pondra node. The [PySpark guide](/pondra/guides/pyspark/)
shows how to move a job. This page lists every name, grouped by what it is for, with an example that runs.

The setup block below starts the session and makes the `orders` table that most examples read. The
file examples start a node of their own on this machine.

## Setup

```python
from pondra.spark import SparkSession, functions as F, Window

spark = SparkSession.builder.remote("pondra://localhost:8080").getOrCreate()
orders = spark.createDataFrame(
    [(1, "ann", "tea", 2, 3.5), (2, "bob", "cake", 1, 4.5), (3, "ann", "tea", 1, 3.5), (4, "cy", "coffee", 3, 3.0)],
    ["id", "user", "item", "qty", "price"])
orders.write.mode("overwrite").saveAsTable("orders")
```

## Session and catalog

| Name | Does |
|---|---|
| `SparkSession.builder` | `.remote(url)` for a node, `.master("local[*]")` for a lake here (`.config("spark.pondra.lake", folder)`), `.config(key, value)`, `.appName(name)` (accepted, not used), `.getOrCreate()` |
| `SparkSession.getActiveSession()` | the session in use, or `None` |
| `spark.sql(query, args=…)` | a DataFrame of a query. `args` fills the `:name` markers |
| `spark.table(name)` | a table or view as a DataFrame |
| `spark.range(n)`, `spark.range(start, end)` | a column `id` from `start` up to `end` minus 1 |
| `spark.createDataFrame(rows, schema)` | a DataFrame of rows. The schema is column names, a string such as `"id int, item string"`, or a `StructType` |
| `spark.catalog.listTables()` | the tables and views, as rows with `name`, `database`, `tableType` and `isTemporary` |
| `spark.catalog.tableExists(name)` | `True` or `False` |
| `spark.catalog.dropTempView(name)` | forgets a temporary view. `True` if there was one |
| `spark.read`, `spark.udf` | the readers of files and the Python functions: see [Readers](#readers) and [Python functions](/pondra/guides/pyspark/#python-functions) |
| `spark.stop()` | ends the session. A session on a lake opened here also closes its connection, and the node stops with the last one; a remote one leaves its node running. It is the last example on this page |

```python
print(spark.catalog.tableExists("orders"), spark.catalog.tableExists("nope"))
print(spark.sql("SELECT id FROM orders WHERE qty > :q ORDER BY id", args={"q": 1}).collect())
print(spark.range(2, 5).collect())
spark.range(2).createOrReplaceTempView("two")
print(spark.catalog.dropTempView("two"), spark.catalog.dropTempView("two"))
print([t.name for t in spark.catalog.listTables() if t.name == "orders"])
print(SparkSession.getActiveSession() is spark)
```

## Columns and sorts

| Name | Does |
|---|---|
| `F.col(name)`, `F.column(name)` | a column. `"t.x"` names column `x` of table `t` in a join |
| `F.lit(value)`, `F.expr(sql)` | a constant, and a SQL expression |
| `column.alias(name)`, `column.name_(name)` | the column under a new name. `name_` is the same: the name `name` is the column's own |
| `column.cast(type)`, `column.astype(type)` | the type, as a name (`"double"`) or a type (`types.DoubleType()`) |
| `isNull()`, `isNotNull()` | a test for null |
| `isin(*values)` | `True` when the value is one of them |
| `between(low, high)` | from `low` to `high`, both included |
| `like(pattern)`, `rlike(regex)` | SQL's `LIKE` (`%` is any text, `_` one character), or a regular expression |
| `contains(text)`, `startswith(text)`, `endswith(text)` | the text is inside, at the start, or at the end |
| `substr(pos, length)` | `length` characters from `pos`, counted from 1 |
| `getItem(key)` | an item of a list, counted from 0 |
| `asc()`, `desc()` | a sort key: nulls first when ascending, last when descending |
| `asc_nulls_first()`, `asc_nulls_last()`, `desc_nulls_first()`, `desc_nulls_last()` | a sort key with the nulls where the name says |

```python
spark.table("orders").select(
    "id",
    F.col("item").like("t%").alias("like_t"),
    F.col("item").rlike("^c").alias("rlike_c"),

    F.col("qty").between(1, 2).alias("one_or_two"),
    F.col("id").isin(1, 3).alias("picked"),
    F.col("user").isNull().alias("no_user"),
    F.col("user").isNotNull().alias("has_user"),
    F.col("qty").cast("double").alias("qty_double"),
    F.col("qty").name_("units"),
).orderBy("id").show()

gaps = spark.createDataFrame([(None,), (2,), (1,)], ["v"])
for key in [F.col("v").asc(), F.col("v").desc(), F.col("v").asc_nulls_last(), F.col("v").desc_nulls_first(),

    print([r.v for r in gaps.orderBy(key).collect()])
print(spark.createDataFrame([(["tea", "cake"],)], ["xs"]).select(F.col("xs").getItem(0).alias("first")).collect())
```

## Windows and rows

| Name | Does |
|---|---|
| `Window.partitionBy(*cols)`, `Window.orderBy(*cols)` | a window spec to start from |
| `WindowSpec.partitionBy(*cols)`, `WindowSpec.orderBy(*cols)` | the same, added to a spec |
| `rowsBetween(start, end)`, `rangeBetween(start, end)` | the rows, or the rows whose order value is in range, from `start` to `end`. Use `Window.unboundedPreceding`, `Window.unboundedFollowing`, `Window.currentRow` (0), or a number of rows (negative before, positive after) |
| `column.over(window)` | the column, computed over the window |
| `Row` | a row of an answer: `row.user`, `row["user"]`, `row.asDict()`. `Row(user="ann")` makes one |

```python
from pondra.spark import Row

o = spark.table("orders")
running = Window.orderBy("id").partitionBy("user").rowsBetween(Window.unboundedPreceding, Window.currentRow)
rows = o.withColumn("running", F.sum("qty").over(running)).orderBy("id").collect()
print([(r.user, r["qty"], r.running) for r in rows])
print(rows[0].asDict())
print(o.withColumn("upto", F.sum("qty").over(Window.orderBy("id").rangeBetween(Window.unboundedPreceding, 0)))
      .select("id", "upto").orderBy("id").collect())
print(Row(user="ann", qty=2).user)
```

## DataFrame columns

| Name | Does |
|---|---|
| `select(*cols)`, `selectExpr(*sql)` | the columns, as names, columns or SQL: `selectExpr("qty * price AS total")` |
| `withColumn(name, col)`, `withColumns({name: col})` | adds a column, or several |
| `withColumnRenamed(old, new)`, `withColumnsRenamed({old: new})` | renames a column, or several |
| `toDF(*names)` | every column's new name, in order |
| `drop(*cols)` | removes columns |
| `columns`, `dtypes`, `schema` | the names; (name, type) pairs; the Arrow schema, whose `names` are the names |
| `printSchema()` | the schema as a tree |

```python
o = spark.table("orders")
```

## Filtering, ordering and distinct rows

| Name | Does |
|---|---|
| `filter(cond)`, `where(cond)` | keeps the rows where the condition holds. A condition is a column, or SQL text such as `"qty > 1"` |
| `orderBy(*cols, ascending=True)`, `sort(...)` | sorts. `ascending=False` reverses it. Columns or sort keys |
| `limit(n)` | the first `n` rows, in the order they have |
| `distinct()`, `dropDuplicates(subset)`, `drop_duplicates(subset)` | one row of each: of all the columns, or of the `subset` columns |
| `sample(fraction)` | about `fraction` of the rows |

```python
o = spark.table("orders")
print(o.where(o.qty > 1).count(), o.filter(F.col("item") == "tea").count())
print(o.select("user").distinct().orderBy("user").collect())
print(o.dropDuplicates(["user"]).count(), o.drop_duplicates(["item"]).count())
print(o.orderBy(F.desc("qty"), "id").limit(2).collect())
print(o.sort("qty", ascending=False).limit(1).collect())
print(o.sample(fraction=1.0).count())
```

## Joins and set operations

| Name | Does |
|---|---|
| `join(other, on, how)` | joins on a column name, a list of them, or a condition. `how` is `inner` (the default), `left`, `right`, `outer` or `full`, `left_semi` or `left_anti` |
| `alias(name)` | names a DataFrame, for a join's condition: `F.col("o.user")` |
| `crossJoin(other)` | every row with every row |
| `union(other)`, `unionAll(other)` | the rows of both, repeats kept, as PySpark does |
| `unionByName(other)` | the rows of both, matched by column name instead of position |
| `F.broadcast(df)` | returns the DataFrame as it is: the node plans the join |

```python
owners = spark.createDataFrame([("ann", "Oslo"), ("bob", "Lima")], ["user", "city"])
o = spark.table("orders")
print(o.join(owners, "user", "left").select("id", "city").orderBy("id").collect())
print(o.alias("o").join(owners.alias("c"), F.col("o.user") == F.col("c.user")).count())
print(o.join(owners, "user", "left_anti").count())
print(owners.crossJoin(spark.range(2)).count())
print(owners.union(owners).count(), owners.unionAll(owners).count())
print(owners.unionByName(spark.createDataFrame([("Bonn", "zed")], ["city", "user"])).orderBy("user").collect())
print(o.join(F.broadcast(owners), "user").count())
```

| Name | Does |
|---|---|
| `show(n)` | prints the first `n` rows as a table |
| `count()`, `first()` | the number of rows; the first row |

## Nulls and conditionals

| Name | Does |
|---|---|
| `F.when(cond, value)`, `.when(cond, value)`, `.otherwise(value)` | a `CASE WHEN`: the first condition that holds gives its value |
| `F.coalesce(*cols)` | the first column that isn't null |
| `F.isnull(col)`, `F.isnan(col)` | a test for null, and for NaN |
| `na.fill(value, subset)`, `fillna(value, subset)` | fills nulls: of the kind of `value` (text, a number, or true or false), in `subset` or every column |
| `na.drop(how, subset)`, `dropna(how, subset)` | drops the rows with a null (`how="any"`, the default), or only where `subset` has one |

```python
gaps = spark.createDataFrame([(None, 1), ("x", None), ("y", 3)], ["s", "n"])
print(gaps.na.fill("z").orderBy("n").collect())
print(gaps.na.drop(subset=["n"]).count(), gaps.dropna().count())
print(gaps.fillna(0, subset=["n"]).orderBy("s").collect())
nums = spark.createDataFrame([(float("nan"), 1.5)], ["a", "b"])
print(nums.select(F.isnan("a").alias("nan_a"), F.isnull("b").alias("null_b")).collect())
print(spark.table("orders").select("id", F.when(F.col("qty") > 1, "many").when(F.col("qty") == 1, "one")
      .otherwise("none").alias("size")).orderBy("id").collect())
print(spark.createDataFrame([(None, "b")], ["a", "b"]).select(F.coalesce("a", "b").alias("c")).collect())
```

## Grouping and aggregates

| Name | Does |
|---|---|
| `groupBy(*cols)`, `groupby(*cols)` | the groups, for `agg` and the methods below |
| `agg(*exprs)` on a DataFrame | the aggregates of the whole DataFrame, in one row |
| `GroupedData.agg(*exprs)` | one row per group, with the aggregates |
| `GroupedData.count()` | the rows in each group, in a column `count` |
| `GroupedData.sum(col)`, `avg(col)`, `mean(col)`, `min(col)`, `max(col)` | the aggregate of a column, named `sum(qty)` and so on |
| `GroupedData.pivot(col)` | raises `NotImplementedError`: write a `CASE WHEN` |
| `F.sum`, `F.avg`, `F.mean`, `F.min`, `F.max` | the aggregate of a column |
| `F.count(col)`, `F.countDistinct(col)`, `F.count_distinct(col)` | the rows, or the distinct values |
| `F.approx_count_distinct(col)` | the distinct values, estimated |
| `F.first(col)`, `F.last(col)` | the first and last value, in the order of the rows. Nulls count (see the caution) |
| `F.stddev(col)`, `F.variance(col)` | the sample standard deviation and variance |
| `F.collect_list(col)` | the values of the group, as a list |

```python
o = spark.table("orders")
print(o.groupBy("user").agg(F.sum("qty").alias("units"), F.avg("price").alias("avg_price"),
      F.countDistinct("item").alias("kinds")).orderBy("user").collect())
print(o.groupby("user").count().orderBy("user").collect())
print(o.groupBy("user").sum("qty").orderBy("user").collect())
print(o.groupBy("user").mean("price").orderBy("user").collect())
print(o.groupBy("user").min("qty").orderBy("user").collect())
print(o.groupBy("user").max("qty").orderBy("user").collect())
print(o.agg(F.count("*").alias("n"), F.count_distinct("item").alias("items"),
      F.approx_count_distinct("user").alias("users"), F.min("qty").alias("least"), F.max("qty").alias("most")).collect())
print(o.agg(F.round(F.stddev("qty"), 3).alias("sd"), F.round(F.variance("qty"), 3).alias("var"),
      F.round(F.mean("price"), 3).alias("mean_price")).collect())
print(o.orderBy("id").agg(F.first("item").alias("first_item"), F.last("item").alias("last_item"),
      F.collect_list("user").alias("users")).collect())
try:
    o.groupBy("user").pivot("item").sum("qty")
except NotImplementedError as e:
    print(e)
```

## Math and text functions

| Name | Does |
|---|---|
| `F.abs`, `F.sqrt`, `F.exp`, `F.floor`, `F.ceil` | the absolute value, square root, e to the power, and the whole number below or above |
| `F.round(col, scale)` | rounds half up to `scale` decimals |
| `F.pow(a, b)` | `a` to the power `b` |
| `F.log(col)` | the natural logarithm of one column |
| `F.greatest(*cols)`, `F.least(*cols)` | the largest and smallest of the columns in each row |
| `F.upper`, `F.lower`, `F.length` | the text in capitals, in small letters, and its length |
| `F.trim`, `F.ltrim`, `F.rtrim` | removes spaces from both ends, the start, or the end |
| `F.substring(col, pos, len)` | `len` characters from `pos`, counted from 1 |
| `F.concat(*cols)`, `F.concat_ws(sep, *cols)` | joins text; the second puts `sep` between the parts |
| `F.regexp_replace(col, pattern, repl)` | replaces every match of a regular expression |
| `F.regexp_extract(col, pattern, group)` | the text of a group of the first match. Group 1 and up (see the caution) |
| `F.split(col, sep)` | the text cut at each `sep`, as a list (see the caution) |

```python
o = spark.table("orders")
print(o.select("id", F.round("price", 0).alias("rounded"), F.abs(F.col("price") - 4).alias("gap"),
      F.pow("qty", 2).alias("squared"), F.sqrt("qty").alias("root"), F.floor("price").alias("down"),
      F.ceil("price").alias("up"), F.greatest("qty", F.lit(2)).alias("big"), F.least("qty", F.lit(2)).alias("small"),
      F.exp(F.lit(0)).alias("e"), F.log(F.lit(1.0)).alias("ln")).orderBy("id").limit(2).collect())
print(o.select("id", F.upper("item").alias("up"), F.lower(F.lit("AB")).alias("lo"), F.length("item").alias("len"),
      F.substring("item", 2, 3).alias("sub"), F.concat(F.col("user"), F.lit("-"), F.col("item")).alias("pair"),
      F.concat_ws("/", "user", "item").alias("who"), F.regexp_replace("item", "[aeiou]", "*").alias("starred"),
      F.regexp_extract("user", "(a)n", 1).alias("letter")).orderBy("id").limit(2).collect())
print(spark.createDataFrame([("  x ", "a,b.c")], ["s", "t"]).select(F.trim("s").alias("trimmed"),
      F.ltrim("s").alias("left_trim"), F.rtrim("s").alias("right_trim"), F.split("t", ",").alias("parts")).collect())
```

Any other of PySpark's functions is the SQL function of the same name, with its arguments in order.
Give a number as `F.lit(…)`, as the examples below do:

```python
print(spark.range(1).select(
    F.sha2(F.lit("s"), F.lit(256)).alias("h"),
    F.pmod(F.lit(-7), F.lit(3)).alias("pm"),
    F.format_string(F.lit("%s-%d"), F.lit("tea"), F.lit(3)).alias("fs"),

).collect())
```

## DeltaTable

| Name | Does |
|---|---|
| `DeltaTable.forName(spark, name)` | a table by its name |
| `DeltaTable.forPath(spark, path)` | raises `NotImplementedError`: a Pondra table goes by its name |
| `alias(name)`, `toDF()` | the same table under a name for a merge; the table as a DataFrame |
| `update(condition, set)` | `UPDATE`. `set` maps each column to SQL text (`"qty + 5"`) |
| `delete(condition)` | `DELETE`, where the condition holds. SQL text, or a column |
| `merge(source, condition)` | starts a `MERGE`, with the steps below and then `execute()` |
| `whenMatchedUpdate(condition, set)`, `whenMatchedUpdateAll(condition)` | updates the matched rows: the columns in `set`, or every column the two share |
| `whenMatchedDelete(condition)` | deletes the matched rows |
| `whenNotMatchedInsert(condition, values)`, `whenNotMatchedInsertAll(condition)` | inserts the source rows with no match: the `values`, or every column the two share |
| `whenNotMatchedBySourceDelete(condition)` | deletes the target rows the source doesn't have |
| `execute()` | runs the merge |

The [Update and merge](/pondra/guides/pyspark/#update-and-merge) section of the guide shows a whole job. Here is each step on a
table of its own:

```python
from pondra.spark import DeltaTable

spark.createDataFrame([("tea", 2), ("cake", 1), ("juice", 0)], ["item", "qty"]).write.mode("overwrite").saveAsTable("stock")
stock = DeltaTable.forName(spark, "stock")
print(stock.toDF().count())
stock.update("item = 'cake'", {"qty": "qty + 5"})
sales = spark.createDataFrame([("tea", 4), ("milk", 9)], ["item", "qty"])
(stock.alias("t").merge(sales.alias("s"), "t.item = s.item")
    .whenMatchedUpdateAll()
    .whenNotMatchedInsert(values={"item": "s.item", "qty": "s.qty"})
    .execute())
returns = spark.createDataFrame([("juice", 0)], ["item", "qty"])
(stock.alias("t").merge(returns.alias("s"), "t.item = s.item")
    .whenMatchedDelete("s.qty = 0")
    .whenNotMatchedBySourceDelete("t.item = 'cake'")
    .execute())
print(stock.toDF().orderBy("item").collect())
try:
    DeltaTable.forPath(spark, "stock")
except NotImplementedError as e:
    print(e)
```

```text
3
[Row(item='milk', qty=9), Row(item='tea', qty=4)]
DeltaTable.forPath: a Pondra table goes by its name (DeltaTable.forName)
```

## Where it differs from PySpark

What Pondra doesn't do, or does differently. Each is a limit you can plan around:

<Aside type="caution">

- What isn't covered raises `NotImplementedError` naming the way round: RDDs (use DataFrame methods
  or `spark.sql`), `pivot` (write a `CASE WHEN`), `readStream` (a materialized view),
  `DeltaTable.forPath` (a Pondra table goes by name).
- There is no Scala or Java client, no `SparkContext`, and no Spark Connect server.
- `printSchema()` and `dtypes` show Arrow's type names (`int64`, `string_view`), not Spark's.
- A UDF runs in Python on the nodes with the imports, helpers and constants it uses. Anything
  else from your notebook (a DataFrame, a connection) is refused with the fix in the message.
- Put `orderBy` last. A `select`, `withColumn` or `withColumns` after it drops the sort.
- Some names don't do all that PySpark's do yet. `sample` ignores its `seed`, so each run picks
  other rows. `unionByName` takes `allowMissingColumns` but doesn't check it. `first` and `last` keep
  nulls: `ignorenulls` is ignored. `regexp_extract` takes group 1 and up: group 0 gives an empty text.
  `split` cuts at a plain text separator, not a regular expression. `F.log` takes one column (the
  natural log), not a base. `show(vertical=True)` prints the usual table. A function takes a number only as `F.lit(…)`: `F.sha2(col, 256)` raises an error, where PySpark takes the plain 256.
- `alias` names a DataFrame in a join only. Outside one, `F.col("o.id")` and `df["id"]` in a
  `select` are errors. In a `where` or a join, `df["id"]` and `df.id` work.

</Aside>
